Public policy: https://lmslifestyle.github.io/privacy/

`index.html` contains the English and Simplified Chinese policy. GitHub Pages publishes the root of `main`.

The simple information, third-party service, choices, children, changes, and contact structure references the open-source [App Privacy Policy Generator](https://github.com/nisrulz/app-privacy-policy-generator), including its no-tracking policy structure. The page uses original wording describing this app; no generator code or template text is copied.

Keep the policy consistent with the app’s actual behavior. Optional questions leave the device, so the policy retains that disclosure even though there are no accounts, ads, or analytics.
